# OpenCharts Indicator SDK 1 (prototype)
Import a .ts file with exactly export default followed by a JSON object and optional semicolon. No executable TypeScript or imports are allowed. Supported kinds: sma, ema, session-candle. Use Indicators > Import indicator, choose a file or paste source, preview and save, then activate on the selected chart. HTF example provides a session candle. Library uses bounded localStorage; settings are shared by indicator ID while activation is per chart. Renderer uses native Lightweight Charts 4.2 primitives. Future boundaries are projected from the last bar interval when not on the time scale; gaps and coarse candles can make these approximate. Full session data must be loaded to calculate true open/high/low. Leave right chart margin to see the candle. Not yet implemented: arbitrary code sandbox, IndexedDB, version history, multiple instances, full drawing SDK, actual lower panes, multi-timeframe data, automatic market calendars, comprehensive replay/performance tests. Run typecheck and tests locally before use.

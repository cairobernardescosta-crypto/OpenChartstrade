# OpenCharts Indicator SDK 1
Import a .ts containing exactly export default followed by a JSON object. No executable TypeScript is run. Supported kinds: sma, ema, session-candle, expression. Expression accepts only bounded OHLCV arithmetic (+ - * / parentheses), with no calls, imports, network or wallet access. Example: {"sdk":1,"id":"typical","name":"Typical price","version":"1.0.0","kind":"expression","expression":"(high+low+close)/3"}.
Use Indicators > Import indicator; preview, save and activate. Includes search, favorites, duplication, name/color/settings editing, export, five prior snapshots, and JSON backup/restore. Storage remains localStorage; duplicates create independent definitions. Activation is per chart; the same definition's settings are shared. Session candle supports editable opening/closing, IANA timezone, weekdays, color, opacity, width, distance and visibility. Future boundary projection is approximate with gaps/coarse candles; complete session history is required. Leave sufficient right chart margin. Historical volume is now passed to mathematical indicators; live-volume updates still require verification.
Not complete: IndexedDB, unrestricted TS sandbox, full drawing API, per-chart independent instances, true lower panes, multi-timeframe requests, visual preview, diagnostic/admin dashboard, incremental updates, comprehensive replay tests. Run local typecheck, lint, unit tests, E2E and build before release.
